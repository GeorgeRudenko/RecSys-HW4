# RecSys — HW4: Association Rules (UCI Online Retail)

Apriori association-rule mining on 17,080 baskets of the UCI Online Retail dataset, in plain JavaScript (no build, no server).

- **Live page:** https://georgerudenko.github.io/RecSys-HW4/week4/
- **Deliverable:** [`week4/`](week4/) — the course starter with the seven `TODO(hw4)` stubs implemented in `script.js`; `index.html`, `style.css`, `transactions.js` and `readme.md` are unchanged.
- **Verification:** [`verification/`](verification/) — the checks cited in the report (self-checks 11/11, brute-force cross-check, browser run, independent recount).

Open `week4/index.html` directly (works from `file://`), press **Run tests**, then **Run rules**.

Data: D. Chen, "Online Retail," UCI Machine Learning Repository, 2015, doi:10.24432/C5BW33 (CC BY 4.0).
